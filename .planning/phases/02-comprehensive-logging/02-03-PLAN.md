Add comprehensive logging to lib/storage.py:

1. **Imports**: Add `from lib.logger import get_logger` at top (after os import)

2. **Module-level logger**: `logger = get_logger('storage')` after imports

3. **_get_redis() logging**:
   - DEBUG: "Creating Redis client" at entry
   - DEBUG: "Redis client created successfully" on success
   - WARNING: "Redis not available (upstash_redis not installed)" when import fails
   - WARNING: "Redis URL/token not configured" when env vars missing

4. **get_value() logging**:
   - DEBUG: "Getting value for key: {key}" at entry
   - DEBUG: "Cache hit for key: {key}" when cache hit
   - DEBUG: "Cache miss for key: {key}" when cache miss
   - DEBUG: "Value retrieved from Redis for key: {key}" on success
   - ERROR: "Failed to get value for key {key}: {error}" on exception

5. **set_value() logging**:
   - DEBUG: "Setting value for key: {key}" at entry
   - DEBUG: "Value saved to Redis for key: {key}" on success
   - ERROR: "Failed to set value for key {key}: {error}" on exception

6. **delete_key() logging**:
   - DEBUG: "Deleting key: {key}" at entry
   - DEBUG: "Key deleted: {key}" on success
   - ERROR: "Failed to delete key {key}: {error}" on exception

7. **batch_update() logging**:
   - INFO: "Batch updating {count} keys" at entry (include count)
   - DEBUG: "Keys in batch: {keys}" (list the keys)
   - INFO: "Batch update successful" on success
   - ERROR: "Batch update failed: {error}" on exception

8. **Public API functions** (get_session, save_session, etc.):
   - DEBUG level for normal operations
   - Include key name in log messages
   - Log failures at ERROR level

9. **Cache operations**:
   - Log cache TTL and size
   - Log cache clear/refresh

Replace all print() calls with logger.error() calls.
