**Logging guidelines:**
- INFO: Normal operations (token refresh, track fetch, name update)
- WARNING: Rate limits, retries, expected transient failures
- ERROR: Actual failures that prevent operation
- DEBUG: Detailed request/response data (only when debugging)
- Always include context (track name, user ID, etc.) in log extras
