<task type="auto">
  <name>Task 2: Create lib/logger.py logging infrastructure</name>
  <files>lib/logger.py</files>
  <action>
Create lib/logger.py with the following components:

1. **Imports**: logging, python_jsonlogger.jsonlogger.JsonFormatter, threading.local for correlation ID storage

2. **Correlation ID Management**:
   - `_correlation_ctx = threading.local()` for thread-safe storage
   - `set_correlation_id(cid: str)` - sets correlation ID for current context
   - `get_correlation_id() -> str` - gets current correlation ID or generates UUID
   - `clear_correlation_id()` - clears current correlation ID
   - Context manager `correlation_scope(cid=None)` for automatic cleanup

3. **JSON Formatter**:
   - Extend JsonFormatter with custom fields
   - Include: timestamp, level, name, message, correlation_id, function, line
   - Format timestamp as ISO8601

4. **Redis Log Handler** (preparation for LOG-02):
   - `RedisLogHandler` class inheriting from logging.Handler
   - Buffer logs in memory (max 100 entries before flush)
   - Flush to Redis via storage.batch_update or storage.set_value
   - Keep only last 500 entries in Redis (list with LPUSH/LTRIM pattern)

5. **Logger Factory**:
   - `get_logger(name: str) -> logging.Logger`
   - Configures logger with JSON formatter
   - Adds StreamHandler for stdout (visible in Vercel)
   - Optionally adds RedisLogHandler if Redis available
   - Log level INFO by default, DEBUG if FLASK_DEBUG set

6. **Convenience Functions**:
   - `log_sync_start()` - logs sync cycle beginning with correlation ID
   - `log_sync_end(success: bool, message: str)` - logs sync completion

Include proper type hints and docstrings. Reference storage.py patterns for Redis operations.
  </action>
